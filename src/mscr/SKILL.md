# mscr

로컬 SQLite에 쌓아 둔 일봉으로 주식을 거르고 들여다보는 도구. 모든 조회는 `{{MSCR}} query` 계열
명령으로 하고, 출력은 항상 **JSON 한 덩어리**다(실패도 `{"error": "..."}` + 종료코드 1).

```bash
{{MSCR}} query <명령> [옵션] --market kr|us
```

{{WHERE}} `--market`(`-m`)을 생략하면
사용자가 화면·설정에서 정해 둔 기본 시장을 쓴다 — **명시적으로 붙이는 쪽이 안전하다.**

## 시작 전에 두 가지를 먼저 읽는다

1. `{{MSCR}} query status -m kr` — 데이터가 어디까지 쌓였는지(`as_of`, `trading_days`, 종목 수).
   `as_of`가 오래됐으면 그 사실을 사용자에게 먼저 알린다. 수집은 사용자가 직접 결정할 일이다.
2. `{{MSCR}} query fields -m kr` — 수식에 쓸 수 있는 이름 전부(시리즈·스칼라·내장 함수·사용자 지표).
   **수식을 쓰기 전에 반드시 확인한다.** 없는 이름을 쓰면 수식이 통째로 거절된다.

## 읽기

| 명령 | 하는 일 |
|---|---|
| `status` | 시장 모드·데이터 기준일·종목 수·최근 수집·자격증명 상태 |
| `markets` | 시장 목록과 각 모드가 지원하는 기능 |
| `fields` | 수식에 쓸 이름·함수 카탈로그 |
| `search <말>` | 종목명·코드 부분 일치 검색 (`--limit`) |
| `quote <티커>` | 최신 시세·재무·보유 포지션 |
| `bars <티커>` | 최근 일봉 OHLCV (`--days`, 기본 120) |
| `chart <티커>` | 차트를 말로 옮긴 구조 요약 — 구간·스윙·수평선·박스·사건 (아래 참조) |
| `screen` | 수식으로 전종목 필터 (아래 참조) |
| `presets` | 저장된 프리셋 목록과 스펙 |
| `stats` | 그날 시장 전체 통계 — 상승/하락, 거래대금, 순위표 (`--date`) |
| `brief` | 장 마감 브리핑 — 프리셋 신규/이탈, 관심종목 목표 도달, 보유 (`--date`) |
| `signals <티커>` | 이 종목이 어떤 프리셋에 언제 걸렸는지 |
| `signal-diff <프리셋>` | 프리셋의 직전 수집일 대비 신규·이탈 종목 |
| `watchlists` / `watchlist [이름]` | 관심목록과 편입 종목 현황 |
| `portfolio` | 보유 종목·현금·평가손익 |

## 쓰기

| 명령 | 하는 일 |
|---|---|
| `watchlist-add <티커> [--list 이름] [--memo] [--target 가격]` | 관심종목 편입(편입가 기록) |
| `watchlist-remove <티커> [--list 이름]` | 편입 해제 |
| `watchlist-create <이름>` | 빈 관심목록 생성 |
| `preset-save <이름> -f "<수식>" [--sort ...]` | 프리셋 저장·덮어쓰기 |
| `preset-delete <이름>` | 프리셋 삭제 |

쓰기는 사용자가 **요청했을 때만** 한다. 특히 `preset-save`는 같은 이름이 있으면 조용히
덮어쓰므로, 먼저 `presets`로 확인하고 겹치면 사용자에게 물어본다.

데이터 수집(`{{MSCR}} ingest`)과 신호 로그 적재(`{{MSCR}} signals capture`)는 오래 걸리고 외부 API를
쓴다. 스킬에서 임의로 돌리지 말고 필요해 보이면 사용자에게 제안만 한다.

## 차트 읽기

```bash
{{MSCR}} query chart 005930 -m kr --window 250 --sketch
{{MSCR}} query chart 005930 -m kr --source alphasquare --freq minute-5 --window 200
```

`bars`가 봉을 그대로 주는 데 비해(250봉 ≈ 40KB) 이쪽은 4KB 안팎이고, 줄어든 자리에 **시간 축**이
남는다 — 언제부터 올랐고 어디서 막혔는지. 종목을 설명해 달라는 요청에는 `bars`가 아니라 이걸 쓴다.

| 열 | 읽는 법 |
|---|---|
| `segments` | 창을 덮는 상승·하락·횡보 구간. 빈틈·겹침이 없고 **라벨은 늘 `change`와 같은 방향**이다 |
| `swings` | 확정된 스윙 고·저점. `confirmed: false`는 아직 되돌림을 못 본 진행 중인 극값이다 |
| `levels` | 두 번 이상 닿은 가격대. `touches`는 스윙 극값 기준이라 실제보다 보수적이다 |
| `box` | 마지막 봉에서 뒤로 넓힌 횡보 폭. `exists`가 false면 나머지 값은 "박스가 아니다"라는 뜻뿐이다 |
| `events` | 봉 하나짜리 사건 — 거래량 급증·갭·이평 교차·신고가. 최근 순 |
| `trend` | 5·20·60·120 이평 배열과 그 상태가 언제부터인지 |
| `sketch` | `--sketch`로만. 창을 60칸으로 줄인 문자 캔들 — 쌍봉인지 계단인지 같은 형태 감각용 |

### 원천 고르기 (`--source`)

화면 차트의 `로컬`/`실시간` 토글과 같다. 기본은 `local`이다.

| | `local` (기본) | `alphasquare` |
|---|---|---|
| 주기 | 일봉만 | `day` · `minute-1/3/5/15/30/60` |
| 최신성 | 마지막 수집일(EOD) | **장중 오늘 봉까지** |
| 가격 | 한국은 캐시된 수정주가가 있으면 그것(`adjusted`), 없으면 원주가 / 미국은 수정주가 | 수정주가 아님(`adjusted: false`) |
| 비용 | 로컬 DB만 읽음 | 비공식 외부 API 호출 — 느리고 실패할 수 있다 |

- **"지금 어때?", "오늘 흐름"** 처럼 장중 상황을 묻거나 **분봉**을 물으면 `--source alphasquare`다.
  그 외에는 `local`을 쓴다. 외부 호출을 습관적으로 하지 않는다.
- alphasquare로 읽었으면 답에 **비공식·수정주가 아님**을 밝힌다. 그게 화면의 경고와 같은 말이다.
- 분봉일 때 `window`는 봉 수다. `minute-5 --window 200`은 200봉 ≈ 약 2거래일이다.

### 옮길 때 지킬 것

- **`bars`는 봉 수지 날짜 수가 아니다.** 일봉이면 거래일, 5분봉이면 5분 봉 개수다. `신고가250`도
  250봉 기준이고, 일봉일 때만 "52주"라고 바꿔 말할 수 있다.
- **`events`의 `count`는 창 전체 횟수**다. `골든크로스 count: 8`은 그 신호가 8번 났다는 뜻이고,
  그만큼 이평이 얽혀 있다는 말이다. "골든크로스 발생"만 옮기면 오해를 만든다.
- `confirmed: false`인 스윙을 "고점을 찍었다"로 단정하지 않는다. "되돌림이 아직 확인되지 않았다"까지 말한다.
- `price_jump_flag`가 true면 액면분할·병합으로 그 이전 구간이 잘렸다는 뜻이다. 창이 짧아진 이유를 밝힌다.
  봉이 20개도 안 남으면 판독 자체가 거절되는데, 그건 종목 탓이 아니라 원천이 수정주가가 아니어서다.
- `segments`만 보고 "상승 중"이라고 옮기지 않는다. 스윙이 없는 조용한 꼬리는 앞 구간에 붙으므로,
  **`box`를 함께 본다** — 두 달째 멈춰 선 것을 구간은 말해 주지 않는다.
- `resolution.swing_factor`는 판독 해상도다. 사용자가 화면에서 본 구간과 어긋난다고 하면
  `--swing-factor`로 조절해 다시 읽는다 — 잔파동까지 보려면 낮추고(1.5~2), 큰 줄기만 보려면 올린다(4~5).
  `swing_threshold`는 그래서 실제로 몇 %를 되돌려야 스윙으로 쳤는지다.
- 이 요약은 **정의한 것만 읽는다.** 삼각수렴·헤드앤숄더 같은 이름은 계산하지 않는다. JSON에 없는
  패턴을 지어내지 않는다.

## 스크리너

```bash
{{MSCR}} query screen -m kr \
  -f "prior_avg_ratio(volume, 20) >= 3 and value >= 5000000000 and close >= 1000" \
  --sort "prior_avg_ratio(volume, 20)" --limit 10
```

| 옵션 | 뜻 |
|---|---|
| `-f, --formula` | 불리언 수식. 이 식이 참인 종목만 남는다 |
| `--preset <이름>` | 수식 대신 저장된 프리셋으로 실행 |
| `--sort` / `--dir` | 정렬 수식(기본 `value`)과 방향(`desc`/`asc`) |
| `--kinds` | `stock`(기본), `etf`, `stock,etf` |
| `--markets` | 거래소 필터 — 한국 `KOSPI,KOSDAQ` / 미국 `NASDAQ,NYSE,AMEX`. 비우면 전체 |
| `--limit` | 기본 20. 결과가 크면 토큰도 커진다 |
| `--min-bars` | 필요한 최소 봉 수(기본 250). 250봉 지표를 쓰면 그대로 둔다 |
| `--as-of-offset` | 0=최신 거래일, 1=하루 전 … 과거 시점 재현에 쓴다 |
| `--columns` / `--full` | 내보낼 열 지정 / 전체 열 |

`--preset`으로 실행하면 유니버스·수식은 저장된 스펙을 그대로 쓰고 `--limit`·`--as-of-offset`만
덮어쓴다. 프리셋의 조건을 바꿔 보고 싶으면 `presets`로 스펙을 읽어 `--formula`로 다시 돌린다.

수식 문법: `and` `or` `not`, 비교식(`>= <= > < ==`), 사칙연산, 괄호. 시리즈(`close`,
`volume`, `value`, `high`, `low`, `open`)는 마지막 봉 값으로 평가되고, 함수는 `fields`가
알려주는 것만 쓴다(`sma` `ema` `rsi` `atr` `returns` `rolling_max` `rolling_min`
`prior_avg_ratio` `crosses_above` `historical_volatility` `slope` `obv` …).

자주 쓰는 골격:

- 거래량 급증: `prior_avg_ratio(volume, 20) >= 3 and value >= 5000000000`
- 52주 신고가 근접: `close / rolling_max(high, 250) - 1 >= -0.03`
- 정배열 추세: `sma(close, 20) > sma(close, 60) and sma(close, 60) > sma(close, 120)`
- 박스 조임: `(rolling_max(high, 20) - rolling_min(low, 20)) / close < 0.08`
- 변동성 낮은 종목: `atr(high, low, close, 14) / close < 0.03`

전 종목을 실제로 계산하므로 한 번에 **10초 안팎**이 걸린다. 조건을 조금씩 바꿔 여러 번
돌리기보다, 한 번에 거른 뒤 결과를 읽고 다음 수식을 정하는 편이 낫다.

## 시장 모드 (한국 / 미국)

두 시장은 완전히 분리돼 있다. 유니버스·일봉·프리셋·관심목록·포트폴리오가 각각이고, 한
명령이 두 시장을 섞어 보는 일은 없다. 사용자가 "미국 주식"을 말하면 `-m us`를 붙인다.

미국 모드에서 다른 점:

- **금액은 달러**다. 수식의 `value`(거래대금)·`close` 기준선을 원화 감각으로 쓰면 안 된다
  (한국 `value >= 5000000000`(50억원) ↔ 미국 `value >= 50000000`(5천만달러) 정도).
- **재무 지표가 없다** — `market_cap` `per` `pbr` `eps` `bps` `div`는 전부 null이다.
  유동성·규모를 걸러야 하면 `value`나 `sma(value, 20)`를 쓴다.
- 거래소 이름이 `NASDAQ` `NYSE` `AMEX` `CBOE` `OTHER`다.
- 계획·주문·리스크·복기와 현재 시황은 한국 전용이라 아예 없다.

## 결과를 사용자에게 옮길 때

- 표는 필요한 열만 추려서 보여 준다. `_sort`는 정렬 수식의 계산값이라, 무엇을 기준으로
  줄 세웠는지 설명할 때만 쓴다.
- 통화 단위를 붙인다(원 / 달러). 미국 종목에 "원"을 붙이지 않는다.
- `bars_available`이 `--min-bars`에 겨우 걸치는 종목은 지표가 불안정하다. 250봉 미만
  종목이 섞이면 그 사실을 밝힌다.
- 이 도구는 **일봉 EOD 기준**이다. 장중 실시간 값이 아니라 `as_of` 날짜의 종가다.
- 스크리닝 결과는 후보 목록일 뿐이다. 매수·매도 판단으로 단정해 말하지 않는다.
